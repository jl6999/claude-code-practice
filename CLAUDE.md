# claude-code-practice

A one-page site about what I learned setting up Claude Code at Opt Digital.

## Rules
- Plain HTML and CSS only: `index.html` plus the `images/` folder. No frameworks, no build step, no npm, no JavaScript libraries.
- This repo is public. No secrets, API keys or private company information.
- Never commit on `main`. Work on a branch and open a pull request.
- The page must read well on a phone and on a laptop.

## Preview
Open `index.html` in a browser (double-click it, or run `start index.html` in the terminal).
To check phone width, press F12 and turn on the device toolbar.

## Deploy
Vercel deploys the site automatically from the `main` branch. A change goes live once its pull request is merged.
